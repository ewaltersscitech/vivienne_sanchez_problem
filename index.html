Worked solution

Choose the clock. Let global t = 0 be the instant Dad's head start begins. Vivienne is stationary for the first 3.00 s. It is also useful to define τ = t − 3.00 as the time Vivienne has actually been accelerating.
1. Vivienne's position equationGeneral: x = x₀ + v₀τ + ½aτ²Substitute: xᵥ = 0 + 0(τ) + ½(0.500)τ²For t ≥ 3.00 s: xᵥ = 0.250(t − 3.00)² mFor 0 ≤ t < 3.00 s, xᵥ = 0.
2. Dad's position equationGeneral: x = x₀ + vtSubstitute: xᴅ = 0 + (4.00)txᴅ = 4.00t mIf instead you reset the clock when Vivienne starts, Dad is already 12.0 m ahead, giving xᴅ = 12.0 + 4.00τ.
3. When does Vivienne catch Dad?Same position: 0.250τ² = 12.0 + 4.00τ0.250τ² − 4.00τ − 12.0 = 0τ = [4.00 ± √(16.0 + 12.0)] / 0.500 = [4.00 ± √28.0] / 0.500The physical root is τ = 18.6 s after Vivienne starts accelerating. Including Dad's head start: t = 21.6 s after Dad starts.
4. Speeds when they meetVivienne: v = v₀ + aτ = 0 + (0.500)(18.583...) = 9.291...Dad: v = 4.00 m/s (constant)Vivienne = 9.29 m/s; Dad = 4.00 m/s.
5. Distance from the original positionx = xᴅ = (4.00)(21.583...) = 86.332...Check with Vivienne: x = 0.250(18.583...)² = 86.332...They meet 86.3 m from the original position.
6. Does Dad have to accelerate to win?
The problem does not give the tree's distance, so this cannot be answered with one unconditional yes/no. At constant 4.00 m/s, Dad stays ahead until Vivienne catches him at 86.3 m. Therefore, if the tree is at or before 86.3 m, Dad can reach it without accelerating. If the tree is farther than 86.3 m, Vivienne catches and passes him, so Dad would need to change his motion to stay ahead.
